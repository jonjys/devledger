For developers with too many accounts

Every account, key and project you've signed up for, on one map.

Which email owns which GitHub, Vercel and Supabase account. Which project uses which database. Where every API key lives, and what it all costs each month. DevLedger keeps it in one encrypted file on your own computer.

What it does

The map

Email → service account → organization → project, drawn as a map you can drag around. See at a glance that three side projects share one Supabase account, or which login a forgotten repo lives under.

A vault per project

Keys are filed where they belong: on the project, the database or the account. Copy one key, or the whole project as a .env file for staging or production, without the value ever being shown.

Smart Paste

Paste a .env file or a dashboard page and DevLedger finds the keys, project refs and plans in it, tells you what it thinks they belong to and asks when it isn't sure. Nothing is saved until you review it.

Subscriptions and trials

Every plan with its price and renewal date, and a warning before a trial quietly turns into a bill.

Needs attention

Keys filed against nothing, resources no project uses, an account with no email. The gaps in your setup, listed instead of discovered at 2 a.m.

Connect Supabase

Optional: give DevLedger a Supabase access token and it reads your organizations and projects so you don't type them in. It only sends read requests, and only when you press the button.

What happens to your data

Short version: it stays on your computer, encrypted, and DevLedger has no server to send it to.

One encrypted file, on your machine

Everything lives in a single SQLCipher database. There is no DevLedger account, no cloud sync, no tracking or usage reporting. Your passphrase is turned into a key with Argon2id (64 MiB, 3 passes) and is never stored.

Keys are sealed twice

On top of the database encryption, every key is sealed on its own with XChaCha20-Poly1305. The interface only ever receives a masked preview like sk_t…3333; the full value is returned only when you press Reveal.

Copy without showing

Copy puts a key straight on the clipboard from the encrypted core, without it passing through the interface, and clears the clipboard again after 30 seconds.

Locks itself

After 15 minutes without use the vault locks, the keys are dropped from memory and the clipboard is cleared. There is no passphrase recovery: lose it and the data is gone, by design.

The network, only when you ask

The app window itself cannot reach the internet. The only outgoing traffic is to Supabase's API, when you press Connect or Refresh: read requests, to an allowlisted host.

What it can't protect you from

Malware on your computer while the vault is unlocked. A forgotten passphrase. It is early software and has not had an independent security audit. The full threat model is on GitHub.

Download

The latest release is on GitHub. Free. Every file below is built by GitHub Actions straight from the public source code, and the build logs are public.

Before you run the Windows installer

The installer is not code-signed yet (a signing certificate is on the way). Until it is, Windows shows a blue “Windows protected your PC” box the first time. That warning is about the missing signature, not something found in the file. To continue, click More info → Run anyway.

Want to be sure you got the exact file GitHub built? Compare its checksum with the one listed below:

# Windows (PowerShell)
Get-FileHash .\DevLedger_x.y.z_x64-setup.exe -Algorithm SHA256

# Linux
sha256sum DevLedger_x.y.z_amd64.AppImage

Windows

The -setup.exe installs for your user only and needs no admin rights. The .msi is the same app for managed installs.

Linux

The .AppImage runs anywhere (chmod +x it first); the .deb is for Debian and Ubuntu.

Android

Install the .apk after allowing installs from your browser. Early, but it is the full app.

iPhone and Mac

Not in the App Store yet, and there is no Mac build yet. The .ipa is unsigned and only installs with a sideloading tool. Until then, the browser demo runs on any device (the map is easiest on a bigger screen).
